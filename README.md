# ноябрь

Лендинг проекта «ноябрь» — Виктор × Анастасия.

> Люди продолжают жить, когда совсем темно, и доживают до света.

**Сайт:** https://r0undm1dn1ghty-star.github.io/november/

## Что это

Одностраничный сайт: hero с фотографией дерева, текстовый проход о ноябре, интерлюдия о возвращении к свету, блок авторов, финал.

Один файл — `index.html`. Стили и фотография героя (webp, base64) внутри файла, шрифты (IBM Plex Sans/Mono, Sofia Sans) и GSAP 3.12.5 — с CDN. Отдельных ассетов нет, сборки нет.

## Как править

Правки — в `index.html`, коммит в `main`, GitHub Pages пересобирает сам за 30–90 секунд.

- Токены темы — блок `:root` в начале `<style>` (фон, цвет текста, шрифты).
- Фото героя — переменная `--tree-image` (data URL).
- Анимации — последний `<script>`; при `prefers-reduced-motion: reduce` весь GSAP не запускается.

## Особенности

- Плёнка (зерно, «поры») — два фиксированных слоя поверх страницы, `pointer-events: none`.
- Мобильная версия — отдельные правила в `@media (max-width: 680px)`.
